Connection

Commands are matched locally, then routed by Jev, TypeSafe AI's System One model. Jev returns a typed decision — it never writes code or text.

Permissions

macOS grants these to a signed app identity. Each one is requested only when it is first needed — nothing is demanded up front.

Voice

Speech recognition

Runs entirely on this Mac. Measured on spoken commands naming installed apps, across four accents: Small was the most accurate and fast enough (~150 ms) to transcribe while you talk. Large v3 Turbo takes ~600 ms a pass, which rules out live transcription — choose it only if Small genuinely struggles with your voice.

Commands

Everything the agent can do. Jev picks from exactly this list — it can never invent a command, and anything not here simply will not run.

JVA

Jev Voice Agent

Realtime voice control for macOS. Say “Hey Jeff” and your Mac does it — usually within half a second of you finishing, and for a chained request, before you have.

Built with

Jev by TypeSafe AI decides what each command means. On this Mac, whisper.cpp (MIT) transcribes, Silero VAD (MIT) hears when you speak, and sherpa-onnx (Apache 2.0) listens for the wake word. Your audio never leaves the Mac; only the words of a command are sent to Jev.
